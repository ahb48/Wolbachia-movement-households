This repository contains the code used to produce the results in the research article "Household scale Wolbachia release strategies into a resident
mosquito population for effective Dengue control" authored by Abby Barlow and Ben Adams, The University of Bath. Scripts are designed to run on a 
high performance computer and are executed using a shell script. The notebooks provided reproduce the figures in the manuscript, where simulation results have been 
provided as data files for the purpose of reproducibility.

In the sensitivity-analysis branch we provide the full set of data files produced in our sensitvity analysis on the dispersal rates of the mosquitoes. For other results in the manuscript we provide the post processes results used for each figure as csv files in the main branch.
